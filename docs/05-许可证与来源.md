# 05 许可证与来源

## 根许可证

本仓库**暂无根 LICENSE**，默认“保留所有权利”（all rights reserved）。
根许可证一旦确定，只覆盖自有内容，不覆盖 `skills/` 下 vendor 的第三方代码。

如果要开源，先确认：

1. 自有内容采用什么许可证（MIT / Apache-2.0 / 其它）；
2. 第三方目录各自的许可证是否允许再分发；
3. 在每个第三方目录保留原 `LICENSE` 与版权行，并在本页登记。

## 判断原则

- 没有明确许可证的内容，一律不复制正文，只登记来源链接。
- MIT / Apache-2.0 可以收录，但必须保留许可证与版权行。
- 修改第三方技能时，在 `UPSTREAM.md` 的“本地改动”写清楚；不要删除原版权信息。
- 引用第三方文档、图片、示例代码同样受版权约束；不确定就不进库。

## MCP 的额外说明

- 仓库只收录配置模板与自写服务；第三方 MCP 的源码不 vendor。
- 模板中不出现 token、账号、真实路径中的用户名。
- OAuth 令牌缓存（如 ms365）属于运行时数据，不进库，也不随仓库迁移。

## 私有性要求

`projects/zcode-persistence/src/error_watch.py` 内置真实收件与发件邮箱，
项目 README、CHANGELOG 与文档中也有引用。因此：

- **本仓库必须保持私有**，不得公开或分享；
- 公开前必须把邮箱改为环境变量或本地配置注入，仓库只保留占位符；
- 文档中不要新增完整邮箱地址；已有地址在公开前统一清理。
