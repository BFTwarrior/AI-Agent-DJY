# 00 总览

## 这个仓库是什么

AI-Agent-DJY 是一个**个人 agent 资产总库**：把技能（skills）、MCP 服务（mcps）和完整项目
（projects）放在同一个仓库里，用一套命名、收录、部署和发版规则管理。

它解决三个问题：

1. **资产分散**：技能在 `~/.zcode/skills`，MCP 配置在 `~/.zcode/cli/config.json`，
   项目散落在 `<workspace>`，没有统一的来源与版本。
2. **改动不可追溯**：直接改运行时副本，出了问题不知道改了什么、怎么回滚。
3. **迁移成本**：换机器或换 agent 平台时，不知道要带走哪些文件。

## 三类资产

```text
skills/     可复用的能力包：SKILL.md + 参考资料 + 来源登记
mcps/       自写 MCP 服务，或第三方服务的配置模板（不含密钥）
projects/   完整项目：源码 + 当前版文档 + 当前版结构图
shared/     跨项目脚本与提示词
docs/       仓库级规范（本目录）
```

三者共用的原则：

- **仓库是源，运行时是副本**。改仓库，再同步；不直接改 `~/.zcode` 下的文件。
- **第三方内容必须可追溯**：许可证、来源、导入时的 hash。
- **旧版本靠 tag 与 Releases**，仓库内不重复存放历史副本。

## 边界：什么不进来

| 类别 | 原因 | 放哪里 |
|---|---|---|
| 密钥、token、真实 `config.json` | 私有库也会被 clone、备份、分享 | 本机环境变量 / ZCode 用户配置 |
| `venv/`、`node_modules/` | 可重建、体积大 | 本机 |
| 构建产物、zip、xmind 原件 | 二进制历史会膨胀 | GitHub Releases 或本机 |
| 日志、sqlite、state | 运行数据、可能含隐私 | 本机 |
| 无许可证的第三方内容 | 默认版权保留 | 只记链接，不复制正文 |

## 与本地目录的关系

```text
<workspace>\
├─ AI-Agent-DJY\                项目文件夹（含 文档/逻辑图/历史）
│  ├─ 文档\  逻辑图\  历史\      项目自身的规划与历史（不进仓库）
│  └─ repo\                     ★ 仓库工作区（唯一 git 根）
│     ├─ skills/  mcps/  projects/  shared/  docs/
│     └─ README.md  AGENTS.md  .gitignore
└─ Zcode-Persistence\           旧目录，迁移后为只读备份
   └─ 历史\                     本地历史原件，保留不删
```

**仓库根是 `AI-Agent-DJY\repo`**。不要在 `AI-Agent-DJY` 根目录初始化 git，
否则规划文档与本地历史会被一起提交。

## 数据流

```text
仓库 skills/<name>/   ──安装──►  C:\Program Files (x86)\AI\AI-Agent-DJY\skills\<name>\
                              └──同步──►  ~\.zcode\skills\<name>\

仓库 mcps/<name>/     ──渲染 + 备份──►  ~\.zcode\cli\config.json  (mcp.servers.<name>)

仓库 projects/<name>/ ──tag/Release──►  GitHub Releases（发行包）
```

细节见 [03-部署与同步](03-部署与同步.md)。

- 不把仓库当密钥保险箱。
