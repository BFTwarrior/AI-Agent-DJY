# Scripts

规划中的跨项目脚本。实现时必须遵守：

1. 默认 `--dry-run`，打印将新增/覆盖/跳过的文件；
2. 真正写入前备份目标到 `%TEMP%\AI-Agent-DJY-backup-<时间>`；
3. 不删除目标里多出来的目录或条目，只报告；
4. 路径用 `pathlib` + `expanduser`，不写死盘符；
5. 失败以非 0 退出，并说明失败原因，不静默吞异常。
