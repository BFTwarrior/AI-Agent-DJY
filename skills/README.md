## 新增技能

1. 建目录 `skills/<name>/`，目录名与 `SKILL.md` 的 `name` 一致；
2. 第三方内容补 `LICENSE` 与 `UPSTREAM.md`（模板见 [02-收录规范](../docs/02-收录规范.md)）；
3. 更新本表与根 `README.md` 的索引；
4. 按 [03-部署与同步](../docs/03-部署与同步.md) 安装到 `AI` 目录，再同步到运行时。
